# 职场寒暄 SOP——中文版

默认环境：中国大陆以中文沟通的职场。本指南考虑本土企业、民企、国企风格团队、专业机构、制造现场、互联网团队及跨国公司中文场景之间的差异，不把任何一种公司文化写成“中国人都这样”。

## 一、什么算成功

一次好的寒暄结束后，双方应当：

- 感到被看见，而不是被盘问；
- 对彼此多一点熟悉，但不背上人情债；
- 可以自然继续、换话题或离开；
- 不必交代隐私，不必假装热情；
- 之后更容易正常协作，而不是更尴尬。

寒暄长短不是成绩。“早，来了”“嗯，早”也可以是一次完整互动。不要用套出了多少私人信息来衡量关系。

## 二、主流程：看—开—接—收

1. **看场**：看时机、场合、关系、层级、隐私和对方信号。
2. **开口**：从共同情境或低压力话题开始，允许对方只回一句。
3. **接球**：先回应，再决定是否轻追问一次，同时适度分享自己。
4. **收尾**：在气氛还轻松时主动结束，给彼此留台阶。

常见时长仅供参考：

- 擦肩而过：5–20 秒
- 电梯、会前：20–90 秒
- 茶水间、食堂：双方都有意愿时 1–5 分钟
- 约好的咖啡或午饭：按约定进行，已经不是临时寒暄

## 三、看场：先判断，再开口

### 3.1 时机灯号

| 信号 | 默认动作 |
| --- | --- |
| 在等人、等电梯、接水，节奏放松，主动看向周围 | 绿灯：打招呼，可试一个轻话题 |
| 边走边整理东西、偶尔看手机、刚落座 | 黄灯：一句问候即可，让对方决定是否展开 |
| 戴耳机专注、正在通话、赶时间、明显烦躁、关门工作、在工位边吃边干 | 红灯：点头或一句“早”；不要强行占用注意力 |

不要把眼神接触、笑容、语速或热情声调当成硬指标。性格、文化、残障、神经多样性、疼痛、疲劳和专注都会影响这些表现。真正重要的是：对方有没有自愿展开或回问。

### 3.2 五个判断

开口前快速过一遍：

1. **时机**：对方现在有空吗？
2. **场所**：别人听到回答，会不会让对方难堪或暴露隐私？
3. **关系**：我们熟到什么程度？过去聊过这个话题吗？
4. **层级**：我的职位、资源或客户身份，会不会让“不回答”变得困难？
5. **渠道**：这句话适合当面、私聊还是群里？是否会留下对方不想留下的记录？

拿不准时就降一级：私人话题 → 工作邻近话题 → 共同情境 → 只打招呼。

### 3.3 权力放大器

在中文职场里，称呼、座位、谁先说话、谁买单、群里是否被点名，都可能放大层级。领导、甲方、面试官、导师、资深同事尤其应当：

- 多用共同情境和工作体验，少问私人生活；
- 先轻度分享自己，再给对方选择是否接；
- 明确说“自愿”“不方便也没关系”，并用行动证明；
- 对方第一次含糊或简短回答时就停止追问；
- 不把聚餐、饮酒、周末活动、群聊活跃或私人分享当成忠诚度；
- 不把寒暄里听到的健康、家庭和时间信息用于排班、晋升或评价。

领导更安全的邀请：“我去楼下买杯咖啡，有人想一起可以来；想自己休息也完全没问题。”

## 四、称呼：先尊重，再亲近

中国职场没有一个通用的最佳称呼。优先级是：本人偏好 > 团队真实惯例 > 行业惯例 > 你的猜测。

### 4.1 第一次见面

- “您好，我是产品部的李宁。请问怎么称呼您？”
- 已观察到团队用法时：“我听大家叫您陈工，我也这样称呼您可以吗？”
- 同级且公司普遍直呼姓名时：“你好，我是李宁，你叫我李宁就行。”

### 4.2 常见称呼的风险

- **某总**：商务、管理层或传统组织中常见，但在扁平团队可能过于正式。跟随本人和团队，不要见人就叫总。
- **老师**：教育、研究、媒体、设计、互联网部分团队常用，也可能显得客套或疏远。不要假设通用。
- **哥/姐**：熟悉团队里可能亲切，也隐含年龄、性别和关系判断。不要初次见面就自行认亲。
- **小某/老某**：可能是既有团队昵称，也可能显得居高临下或冒犯年龄。不要替别人创造。
- **帅哥/美女/小姐姐**：不适合作为默认职业称呼。
- 英文名、昵称、缩写：只在本人使用或同意时采用，不要擅自改名。
- **师傅**：制造、维修、物流、工程现场和部分服务场景常见；办公室内部未必适用，跟随本人和现场惯例。
- **某工**：工程、研发、建筑等技术场景常见，应基于真实岗位和本人偏好。
- **主任、处长、科长等**：正式机构中可能常见，只使用真实职务，不自行升格。

记错了就简短修复：“不好意思，我刚才叫错了。您是周宁，对吧？”之后认真改正，不要躲着不叫。

### 4.3 关系温度一次只升一级

- 陌生或层级差明显：共同环境、工作邻近话题，最多一次跟进。
- 熟面孔：可聊饮食偏好、公开兴趣、通勤类别和宽泛休息安排。
- 稳定合作：只在对方主动披露后，跟到相近或略浅的深度。
- 私下已成朋友：私下知道的事也不能自动带进群聊、饭局、绩效或客户场景。

观察至少几次真实互动，必要时问带教、入职伙伴或可信同事：“大家平时称呼和群聊是什么风格？”先用最低亲密度版本，对方主动提高后再跟随。对方分享过一次，不等于以后都能问；私聊说过，不等于允许转述。

## 五、开口：从低压力处开始

### 5.1 四类自然开场

#### 问候 + 状态温度

- “早，今天怎么样？”
- “好久没在办公室碰到了，最近还好吗？”
- “下午好，刚开完会？”

“最近忙吗”很常见，但也可能把对话引向加班或绩效。对不熟的人可以只说共同情境：“早，刚开完会？”“今天电梯人真多。”

#### 共同情境

- “今天电梯比平时快多了。”
- “这间会议室空调有点猛，你坐这边会不会好些？”
- “刚才那个演示里，自动化那段挺有意思的。”

#### 工作邻近，但不是偷偷派活

- “你最近做的项目里，哪一块最有意思？”
- “上次你讲那个图特别清楚，你之前也做过类似分析吗？”
- “你当初怎么开始做这个方向的？”

真有任务、催办或请求，就尽早说清楚。不要“寒暄半天，最后突然催活”。

#### 吃饭、通勤、兴趣和休息

- “中午有想吃的吗？我还没决定。”
- “这附近你有推荐的安静咖啡店吗？”
- “最近有看什么轻松的剧吗？我想找个下饭的。”
- “周末有什么期待的吗？或者就准备休息？”

不要默认对方有钱旅行、有双休、有车、有伴侣、有孩子、能吃某种食物或愿意聊家庭。

### 5.2 一个低审问感的结构

用 **看见—轻问—自报一点**：

“刚才你提到那家面馆（看见）。味道怎么样（轻问）？我最近正好吃腻了楼下那几家（自报一点）。”

有时候不问也更自然：

“今天外面风真大。我差点把文件吹跑。你先忙，我去接水。”

### 5.3 把问题改得容易拒绝

| 高风险问法 | 更安全的替代 |
| --- | --- |
| “你到底哪里人？” | “你现在常驻哪个城市？”或不问；对方提到城市后再跟随 |
| “多大了？哪年毕业的？” | 讨论岗位经验：“你做这个方向多久了？”仍需看语境 |
| “结婚了吗？有对象吗？” | 默认不问；对方主动提到伴侣时沿用其用词 |
| “怎么还不要孩子？” | 不问 |
| “工资多少？年终奖几个点？” | 除非是双方自愿、无权力压力的明确薪酬互助场景，否则不作为寒暄 |
| “房子买哪儿了？多少钱？” | “通勤还顺利吗？”也允许一句带过 |
| “怎么胖了/瘦了/气色不好？” | 不要换个问法继续根据外貌推断。正常问候即可；若本来就负责工作量检查，应对所有人使用同一个中性问题。 |
| “你这口音是哪儿的？” | 不把口音当竞猜；必要时问“刚才那句我没听清，可以再说一遍吗？” |
| “为什么不喝酒/不吃这个？” | “喝酒还是无酒精？都可以。”接受选择 |
| “朋友圈里那个人是谁？” | 朋友圈可见不等于同意在工作场合讨论，不主动追问 |

## 六、接球：回应，不盘问

### 6.1 一条线原则

从对方自愿给出的一个细节继续，不要连续换类别。

> 甲：“周末去爬了个小山。”
>
> 乙：“那挺放松的。路线难吗？”
>
> 甲：“还好，主要是风景不错。”
>
> 乙：“那很值。我上次爬山一路只顾着喘，风景全错过了。”

乙先回应，轻追问一次，再分享自己；没有继续问和谁、开车还是打车、花多少钱、住在哪里。

### 6.2 接球三步

1. **接住重点**：“这周确实排得挺满。”
2. **有空间才追问一次**：“最费劲的是哪一块？”
3. **对等分享一点**：“我这周也被会切得很碎。”

分享深度要相当。对方只说“还行”，不要用很私密的故事逼出更深交流。

### 6.3 识别中文里的含蓄收尾

以下单独出现未必代表拒绝，但连续出现时应当停：

- “还行”“就那样”“没啥”“一般般”等无细节回答；
- 没有回问，也没有新信息；
- “最近有点忙”“回头再说”“先这样哈”；
- 视线回到屏幕、身体转向出口、开始收东西；
- 在聊天工具上只回表情、收到、嗯嗯，或长期延迟；
- 笑一下但不接内容、迅速换题。

不要逼对方说一句很硬的“我不想聊”。你可以替双方铺台阶：“好，那你先忙，回头见。”

### 6.4 别怕停顿

问完给对方时间。不要马上补三个问题，也不要替对方解释。对使用第二语言、听障、处在嘈杂环境或需要更多处理时间的人尤其如此。

停顿久了可以说：

- “没事，我就是打个招呼。”
- “你先忙，我不打扰了。”
- “不着急回答，回头有机会再聊。”

## 七、收尾：把台阶铺好

### 7.1 通用结构

**转场或理由 + 友好结束**

- “我去接杯水，回头见。”
- “不耽误你了，祝下午那个汇报顺利。”
- “我得去下一个会了，刚才聊得挺开心。”
- “你先忙，等这阵过去再聊。”

理由不用编得很复杂，也不要随口承诺一顿永远不会约的饭。

### 7.2 自己想结束

- “我先回去处理一下手头的事，回头见。”
- “我今天有点累，想安静待会儿，改天再聊。”
- “这个话题我先不展开了，我们聊点别的？”

### 7.3 对方想结束

第一次就放行：“好，你先忙。”“没问题，回头见。”不要在对方转身时再补一个私人问题。

## 八、话题阶梯

### 8.1 一级：通常低压力

- 当下环境、天气、公开交通信息；
- 工作邻近的工具、技能、学习和公开项目；
- 餐馆、书影音、公开活动、通用兴趣；
- 宽泛的休息和计划，带“也可能就在家休息”的出口；
- 对具体行为或能力的感谢。

夸具体贡献通常比夸外貌更稳妥：“你刚才把风险讲得特别清楚”优于“你今天真漂亮/真帅”。

### 8.2 二级：等对方先打开

- 老家、地域、方言和成长经历；
- 伴侣、父母、孩子、照护责任；
- 住房、买车、旅行开销、个人消费；
- 身体、健身、饮食、病假、心理状态；
- 年龄、毕业年份、经济压力或职业变动；
- 对方主动提到的个人节日、饮食习惯和家庭安排；
- 相亲、恋爱和社交生活。

这些在某些中国团队很常见，不代表低风险。对方主动说过一次，也只代表那次、那个范围可以聊。

### 8.3 三级：不要作为寒暄主动发起

- 生育计划、怀孕、疾病诊断、用药、残障原因；
- 性取向、性别经历、民族、户籍、移民身份、政治立场、宗教归属或信仰细节；
- 体重、身材、发量、肤色、年龄和“看起来像不像某地人”；
- 性生活、情感空窗、外貌评价或可能被理解为搭讪的内容；
- 在层级压力下打听个人工资金额、奖金、负债、家产或房价承受力；
- 关于缺席同事的传闻、绩效、家庭、健康或关系；
- 以性别、地域、民族、口音、学校、年龄、职业或身体为笑料；
- 为什么不喝酒、不吃某种食物、不参加团建、不看镜头、不加私人微信。

对方自己提起高敏感话题时可以简短倾听，不要顺势调查。涉及管理、HR、申诉或安全责任时，结束寒暄模式并按制度处理。

同事自愿讨论工资、工时和工作条件，不属于本指南要禁止的“越界寒暄”。不得用话题分级剥夺适用法律保护的讨论或组织权利。

## 九、中国职场高频场景

层级、身份边界、场合、用餐人数和性质的详细组合，见[角色 × 场景矩阵](role-scenario-matrix.md)。

如果要根据上级可观察的偏好调整表达长短、顺序、节奏、细节和渠道，可选读[管理者沟通偏好附加章](manager-style-addon.md)。它不做人格诊断。

### 9.1 新入职或第一次见

目标是降低陌生感，不是考核“会不会来事”。

1. 说姓名、部门和工作连接。
2. 给一个有用的小信息。
3. 问一个容易回答的问题。
4. 主动结束。

“你好，我是运营的周宁，后面上线排期我们会常对接。茶水间在走廊尽头，安静工位在另一边。这一上午还顺利吗？”

不要强制新人公开分享感情状态、家乡段子、才艺、糗事、梦想或“最特别的标签”。

### 9.2 电梯、走廊、打水

- 先问候或说共同情境。
- 不堵住路，不追着走。
- 一个问题后看对方是否展开。
- 电梯门开、对方回工位时自然结束。

电梯是封闭空间，不适合批评、派紧急任务、搭讪或问对方必须在到站前回答的私人问题。

### 9.3 食堂、午饭和茶水间

- 可以从“吃什么”“哪家排队少”开始，不评论饭量、体重或饮食原因。
- 邀请要给退出：“我们 12 点半去楼下，想一起就来；想自己休息也没事。”
- 一个人吃饭可能是在恢复精力，不等于孤僻。
- 不追问“你怎么吃这么少”“减肥吗”“为什么不吃肉”。

### 9.4 会前、培训和团建

- 问所有人都能低成本参与的话题，不只和领导或熟人聊。
- 不做强制轮流的隐私型破冰。
- 给“跳过”选项，并让跳过真的没有后果。
- 会议开始就停，不把后到的人排除在小圈子外。

更安全的破冰：“愿意的话，分享一个最近提高效率的小工具，也可以直接跳过。”

### 9.5 微信、飞书、钉钉和企业群

文字寒暄会留下记录，也容易制造下班后的持续压力。

- 有工作目的时先说明，别只发“在吗”让对方等。
- 纯社交信息写清“不急回”“有空再聊”。
- 一个表情、收到或简短回复可以是完整回应。
- 不连发“？”“人呢”“怎么不回”。
- 不把私聊内容搬到群里，不在群里公开追问私人话题。
- 朋友圈、头像、状态和背景图可见，不等于同意被评论或转发。
- 非必要不在深夜用社交寒暄试探对方是否在线；遵守团队边界。
- 拍摄、录制、发布、转发或标注职场照片和视频前，分别取得同意。参加活动或出现在镜头里，不等于同意公开。集体照应提前说明用途，并提供不入镜且不被点名的选择。

工作目的清楚：“早，想确认一下发布说明用哪个版本，上午 11 点前回我即可。”

管理者非必要不要在深夜发送；先存草稿或定时到次日工作时间。一句“不急回”不能消除下属看到通知后的压力。

纯社交可选：“看到你说去听了那个分享，有空时想听听感受，不急回。”

### 9.6 领导和下属

领导应当：

- 先问工作体验和资源，再考虑个人生活；
- 不借关心打听健康、婚育、家庭、住址和周末可用性；
- 不在公开场合问难拒绝的问题；
- 不把社交活跃、饭局表现、喝酒或加私人微信当成团队融入；
- 不用“小道消息式寒暄”传递绩效反馈；
- 对私密披露说明保密边界和可用支持。

“这周工作量怎么样？要不要一起调一下优先级？”比“你脸色不对，家里出什么事了？”更安全也更有用。前者应是对所有人的常规工作检查，不是看到某人外貌后临时推断。

下属不需要靠打听领导家事、夸外貌或持续陪同来证明尊重。围绕公开兴趣、团队进展和具体感谢即可。

### 9.7 跨部门、甲乙方和客户

- 初次略正式，再根据对方偏好调整。
- 从共同项目、活动内容、行业兴趣、路线和场地信息开始。
- 寒暄不能替代明确的需求、范围、报价和决策。
- 不通过闲聊刺探竞争信息、内部人事或未公开计划。
- 不拿同事、客户或地域开玩笑来“活跃气氛”。

### 9.8 商务饭局和酒精

一起吃饭可以维护关系，但不能把身体选择变成忠诚测试。

- 提供无酒精饮料，不追问原因。
- 不劝酒、不灌酒、不用“不给面子”“感情深一口闷”。
- 不因不喝酒、早退、饮食限制或不参加夜场减少工作机会。
- 不用起哄、暧昧玩笑、身体评论或私人审问助兴。
- 遵守公司礼品、招待、反腐败和报销政策。

拒绝：“我不喝酒，拿茶跟大家碰一下。”重复时：“真不喝，我就用这个。”

旁人解围：“他喝什么自己定。来，大家随意。”

### 9.9 出差、拼车和住宿场景

- 可聊行程、会议、城市公共信息和专业兴趣。
- 不追问确切房间、是否独住、夜间安排或感情状况。
- 尊重休息、祈祷、照护电话、无障碍、饮食和安全安排，不要求解释。
- 同车、同酒店或在外地不意味着边界变宽。

### 9.10 节假日前后

- “假期准备怎么过？不方便说也没事”仍可能触及家庭、钱和返乡压力；不熟时可改为“假期好好休息”。
- 不问为什么不回家、有没有对象、红包给多少、孩子成绩如何。
- 对春节、清明、宗教节日或纪念日，不默认所有人体验相同。
- 节后可以问“休息得怎么样”，也接受“就那样”并转回工作。

### 9.11 病假、丧亲、产假或其他离岗后返岗

只知道对方离开过：

- “欢迎回来。你先安顿；需要补哪部分进度，随时找我。”
- “见到你很高兴，离开的事不用解释。”

对方已主动披露困难：

- “听到这个消息很难过。”
- 与职责相关时：“细节不用讲，工作上现在什么支持最有帮助？”

不要追完整经过、比较谁更惨、给诊断、公开转述或要求对方表现得“恢复正常”。

### 9.12 生产、实验室、医疗和安全现场

安全程序高于寒暄。不要在需要专注、穿戴防护、交接班、操作设备、处置客户或患者信息时分散对方。等到指定休息区或工作完成后再聊。任何保密信息都不能作为闲聊素材。

现场话术应当短而具体：

- “刚交完班？你先休息，晚点见。”
- “李老师，刚下课？您先喝口水，回头聊。”
- “你先把操作做完，不急着聊。”

零售、酒店、物流、医疗等一线场景中，客户、患者、乘客或交付正在等待时，不延长同事寒暄。客户表现友好，也不代表同意私人联系、搭讪或工作外邀约。

## 十、包容与可达性

### 10.1 内向、社交焦虑和低电量

- 安静不等于态度差、能力差或不合群。
- 给可预期的小场景，不突然点名表演。
- 接受文字参与、准备好的话、短回答和提前离开。
- 不用寒暄熟练度评价“情商”或文化适配。

自用表达：“我今天有点累，想安静待会儿，改天再聊。”

### 10.2 神经多样性

- 不强制眼神接触、同步表情、快速接梗或理解暗示。
- 需要结束时直接但友好：“我现在要专注了，回头再聊。”
- 不把讽刺或阴阳怪气当作唯一拒绝信号。
- 给处理时间，不填满每个停顿。
- 问沟通方式，不问诊断：“文字说还是快速通个电话更方便？”

### 10.3 残障和健康

- 面向本人说话，不绕过本人只问陪同者或手语翻译。
- 未经允许不触碰身体、轮椅、拐杖、导盲犬或其他辅助设备。
- 帮忙只问一次，并让拒绝容易：“需要我帮你扶一下门吗？”
- 不索要医疗解释。
- 组织社交时提供安静、可坐、字幕、无障碍和文字选项。
- 把“不接触”当作正常选项。拿不准时先口头问候或轻轻挥手，不要先伸手拥抱再让对方艰难拒绝。
- 对方退开后不要继续靠近，不堵出口；过去拥抱过也不代表永久同意。

### 10.4 普通话、方言、口音与第二语言

- 口音不是智力或专业能力。
- 没听清就为沟通负责：“刚才那句我没听清，能再说一遍吗？”
- 不模仿口音，不把同事当方言表演者，不因名字或声音猜籍贯。
- 不经同意纠正表达或突然切换语言。
- 自己需要时可说：“普通话不是我最熟悉的语言，麻烦稍微慢一点。”

### 10.5 性别、称谓和身份

- 使用本人提供的姓名和称谓，不要求解释身份。
- 不根据外貌、衣服、声音、伴侣或姓名猜性别与关系。
- 叫错后简短改正，不让对方安慰你。
- 遵守法律和公司制度；尊重不以满足你的好奇心为前提。

## 十一、边界、修复和升级

### 11.1 别人问了你不想答的问题

从轻到重选择：

- 转开：“没什么新鲜的。你们那个上线怎么样了？”
- 说明边界：“这个我一般不在工作里聊。”
- 明确停止：“这个比较私人，我就不回答了。”
- 结束：“我先回去处理事情，回头见。”

你不欠对方理由、笑脸或另一个私人信息。

### 11.2 自己问过界了

用 **承认—放行**：

“不好意思，刚才问得有点私人，不用回答。”

到这里先停。只有对方愿意继续互动时才换安全话题。不要说“我只是关心你”“大家都这么问”，不要反复确认“你没生气吧”，也不要换个说法继续问。

### 11.3 叫错姓名或称谓

“抱歉，是周宁。”改正后继续。公开或反复出错时，私下认真道歉并改变行为，不要求对方负责消除你的尴尬。

### 11.4 玩笑或评论冒犯了人

1. 停止，不解释“笑点”。
2. 说：“刚才那句话不合适，对不起。”
3. 不要求被冒犯的人当场接受。
4. 改掉行为；若影响发生在公开场合，在适当范围内纠正。

### 11.5 遇到八卦

- “这个我不了解，就不猜了。”
- “这应该由本人来说。”
- “如果是工作问题，我们直接找他确认吧。”

不要用追问、表情、截图或“就咱俩知道”奖励八卦。

### 11.6 作为旁观者

在安全前提下，用足够有效且不过度抢夺当事人控制权的方式：

- “我们换个话题吧。”
- “不喝不用解释。”
- “这个玩笑不合适。”
- “工作问题我们直接找本人确认。”

事后私下询问当事人需要什么，不擅自公开其身份和经历。行为严重、反复、存在权力差或安全风险时，即使行为人是客户或业绩骨干，也应按制度升级。

### 11.7 私人或浪漫邀约

公司制度允许时，同级之间的私人邀约最多一次。拒绝、不回复、转题、“下次吧”“我看看”或含糊推迟，都应视为结束；不得换私人账号继续邀请、追问原因，或让之后的工作变尴尬。

管理者及掌握排班、项目、评价或机会的人应遵守公司关系与利益冲突政策，不应向直接下属发起浪漫邀约。友好、一起吃饭、出差、团建或饭局，都不构成浪漫同意。

### 11.8 对方披露严重问题

退出寒暄模式：

1. 感谢对方愿意说。
2. 非职责所需不要调查。
3. 问当下需要什么，并说明保密边界。
4. 按公司支持、HR、工会/职工代表、申诉、伦理、安全或紧急流程处理。

若存在即时人身危险或紧急医疗风险，使用所在地紧急程序。本指南不是危机干预或法律意见。

### 11.9 反复、歧视、性意味、胁迫或报复

这不再是“不会聊天”。在安全前提下记录事实，使用公司制度、问题链条之外的管理者、HR/员工关系、工会或职工代表、申诉/伦理渠道及适当主管机关。受到影响的人不必先私下教育或对质行为人。

## 十二、常见失败与替代

| 失败方式 | 对方感受 | 替代动作 |
| --- | --- | --- |
| 查户口式连问 | 被审视、被归类 | 只追一个自愿细节，然后回应或分享 |
| 见领导热、见同事冷 | 寒暄成了向上经营 | 主动覆盖同级、新人、支持岗位和远程同事 |
| 先聊后催 | 友好成了陷阱 | 尽早说明工作目的 |
| 强行积极 | “还行”都不被允许 | 接受中性和困难回答，不急着教育或打鸡血 |
| 比惨或抢故事 | 对方的话被盖住 | 自己只说一句，再把注意力还回去 |
| 自动给建议 | 倾诉变成改造项目 | 问“你是想先聊聊，还是一起看看怎么处理？” |
| 拿熟人隐私找话题 | 不安全、会被传播 | 只聊本人公开且愿意延续的内容 |
| 无限收尾 | 说再见后又开三题 | 第一次收尾就真的结束 |
| 过度模仿江湖气 | 假亲密、油腻 | 轻度跟随正式程度，保留自然表达 |

## 十三、四周练习

### 第一周：让问候变容易

- 准确记住并使用三位同事的名字。
- 每天一次路过式问候。
- 练一句自然收尾。

### 第二周：练互惠

- 用一次共同情境开场。
- 抓住一个细节，只追问一次。
- 分享一句自己，然后停。

### 第三周：练读信号和边界

- 观察谁喜欢展开、谁偏好简短。
- 连续不展开时主动结束。
- 为自己练一句边界表达。

### 第四周：扩大包容范围

- 问候一位不在自己熟人圈或层级圈的同事。
- 试一次异步、低压力的社交接触。
- 检查自己最常用的话题是否默认了钱、房、婚育、身体、地域或空闲时间。

记录“有没有做到尊重”，不要记录“有没有变受欢迎”。一次成功可以是：“我打了招呼，发现对方很忙，就友好离开。”

## 十四、团队和管理者怎么用

团队可以创造连接机会，不能强制亲密。

- 公布可选社交时间，也保留安静选项。
- 活动考虑班次、时区、照护、残障、饮食、宗教、成本和酒精偏好。
- 轮换形式：两人小聊、文字问题、兴趣频道、会前两分钟、完全不参与。
- 决策和重要信息必须回到正式工作渠道。
- 不考核群聊活跃、镜头、聚餐、饮酒、团建或外向程度。
- 带领者先接受权力、隐私、骚扰边界和修复训练。
- 不得把本礼仪指南当作禁止员工依法讨论工资、工时、工作条件、组织活动或其他受保护行为的纪律工具。

安全问题：“愿意的话，说一个最近帮你省时间的工作技巧；也可以跳过。”

不安全问题：“每个人必须说一个从没告诉过别人的秘密，快速建立信任。”

## 十五、最后的判断规则

拿不准时：

1. 话题再浅一点；
2. 问一个，不问三个；
3. 主动给台阶；
4. 第一次边界就相信；
5. 不让工作机会依赖社交参与。

标准是“有温度，也有自由”。两者冲突时，先保护自由。
