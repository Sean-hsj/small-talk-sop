# 中文职场寒暄——一分钟速查

适用于以中文沟通的中国职场。本人偏好和团队真实惯例，优先于地域、行业、年龄等概括。

## 看—开—接—收

| 步骤 | 怎么做 | 可以说 |
| --- | --- | --- |
| **看场** | 看时机、场所、关系、层级、隐私和渠道 | 忙碌时一句“早”就够 |
| **开口** | 共同情境 + 一个容易不回答的问题 | “早，刚开完会？” |
| **接球** | 回应重点 → 最多轻追问一次 → 分享一点 | “那挺放松的。路线难吗？我最近也想多走走。” |
| **收尾** | 趁轻松时结束，不重开新题 | “你先忙，回头见。” |

## 继续还是退出

**可以继续：** 主动给细节 + 回问 + 引出新线索 + 愿意停留。

**该退出：** 连续短答 + 不回问 + 转回屏幕/出口 + “最近忙”“回头说” + 延迟或只发表情。

一次短答可能只是风格；连续两个低投入信号，就降级或结束。不要逼对方明确拒绝第二次。

## 先看角色

- **同级：** 提问和分享大致平衡。
- **下属：** 话题更浅，退出可信，不藏评价。
- **直属上级：** 正常说话；真有工作请求尽早点明。
- **加一、加二：** 一句公开情境，结束或另约正式渠道。
- **副职、矩阵上级：** 尊重真实分工，冲突回正式渠道确认。

性别、年龄、伴侣、婚姻和孩子，只使用对方主动披露的信息。详见[角色 × 场景矩阵](role-scenario-matrix.md)。

遇到上级的重复工作偏好，用“观—猜—问—试—校”。见可选的[管理者沟通偏好附加章](manager-style-addon.md)，不得做人格诊断。

## 称呼顺序

本人介绍 > 名牌/签名 > 团队惯例 > 直接询问 > 自己猜。

- “您好，我怎么称呼您比较合适？”
- “您好，我是新来的陈嘉。请问怎么称呼您？”
- “我听大家叫您陈工，我也这样称呼您可以吗？”
- 不默认使用“总、老师、哥、姐、小某、老某、美女、帅哥”。

## 话题阶梯

### 通常低压力

- 共同环境、会议、公开天气和交通
- 工作邻近的工具、技能、学习和公开项目
- 餐馆、书影音、公开活动和宽泛兴趣
- 带“也可以休息”的周末问题
- 对具体贡献的感谢

### 等对方先打开

- 老家、学校、年龄、伴侣、父母、孩子
- 健康、病假、住房、经济压力、职业变动和饮食原因
- 对方主动提到的个人节日、饮食习惯、家庭安排和困难

### 不主动当寒暄

- 婚育时间、怀孕、疾病诊断、用药、残障原因
- 性取向、性别经历、民族、户籍、政治、宗教归属或信仰细节
- 在层级压力下打听工资金额、奖金、债务、身体、体重、外貌或恋爱可得性
- 八卦、未公开项目、身份玩笑、为什么不喝酒/团建/开镜头

不存在绝对安全的话题。跟随具体的人，不跟随标签。

## 常用句

### 开口

- “早，今天怎么样？”
- “你好，我是运营的周宁，后面会在上线项目上配合。”
- “刚才那个演示挺有意思，你觉得哪一段最有用？”
- “中午有想吃的吗？我还没决定。”

### 接球

- “这周确实排得挺满。”
- “你最喜欢哪一部分？”
- “我最近也想试试。”
- “没听清最后一句，可以再说一次吗？”

### 收尾

- “你先忙，我不打扰了。”
- “我去准备下一个会，回头见。”
- “不占你时间了，祝下午汇报顺利。”

### 设边界

- “这个我一般不在工作里聊。”
- “这个比较私人，我就不回答了。”
- “请不要碰我。”
- “不用了，我不喝酒。”

### 修复

- “不好意思，刚才问得有点私人，不用回答。”
- “刚才那句话不合适，对不起。”
- “抱歉，是周宁。”改正后继续。

### 微信/飞书/钉钉

- 工作目的放在第一条，不要只发“在吗”。
- 社交信息写“不急回”；尊重时区、下班、状态和频道。一个表情或一句“收到”就可以结束。
- 不把私聊、朋友圈、照片或健康家庭信息搬进群里。
- 拍摄、录制、发布、转发或标注职场照片和视频前分别取得同意；参加活动不等于同意公开。

### 接触和私人邀约

- 拿不准时先口头问候或挥手；未经允许不拥抱、不碰身体或辅助设备。
- 私人邀约最多一次。拒绝、不回复、转题或含糊推迟都表示结束，不换渠道再试。

## 管理者规则

权力越大，话题越浅，出口越明显。不把饭局、喝酒、团建、镜头、群聊活跃、私人分享或加微信和工作机会挂钩。

只调整长短、顺序、节奏、细节和渠道，不改变事实、伦理、同意和必要异议。辱骂、歧视、报复和不安全要求不是沟通风格。

## 紧急刹车

反复、性意味、歧视、胁迫、报复或威胁行为，不是“不会聊天”。使用公司申诉、HR/员工关系、安全、工会或职工代表及适当外部渠道。本卡片不是法律或危机处理意见。
